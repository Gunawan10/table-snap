TableSnap Privacy Policy

Last updated: September 4, 2026

TableSnap is developed by Snowman Labs. This Privacy Policy explains how TableSnap handles data when you use the extension.

Data collection

TableSnap does not collect, transmit, sell, or share personal information, browsing history, or table content.

Table processing

TableSnap accesses HTML table content on the web page only to provide CSV, Markdown, and PNG export functionality. Table content is processed locally in your browser and is not transmitted to Snowman Labs or any external server.

Extension settings

TableSnap stores user preferences locally using Chrome extension storage. These preferences may include icon visibility, icon position, icon size, theme, accent color, default export format, CSV delimiter, and image scale.

Third-party services

TableSnap does not use advertising services, analytics services, tracking technologies, or external APIs to collect or process user data.

Remote code

TableSnap does not execute remotely hosted code. JavaScript required by the extension is packaged with the extension and runs locally in the browser.

Changes to this policy

This Privacy Policy may be updated if TableSnap's functionality or data practices change. The latest version will be published on this page.

Contact

For privacy questions, contact the developer through the contact information provided on the TableSnap Chrome Web Store listing.
